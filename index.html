My workflow begins with authoring a BIM Execution Plan (BEP) — establishing naming conventions, LOD milestones, CDE protocols, and task team responsibilities per ISO 19650. I then set up the Common Data Environment (BIM 360 / ACC), onboard all discipline leads, and establish a weekly coordination cycle: model uploads → federated model build → Navisworks clash detection → issue tracking → resolution → sign-off. Python scripts automate clash reporting and compliance checks, reducing manual effort by up to 70%.
